# RUNBOOK — research-mcp

Local MVP on the shared computer. Prepaid Stripe credits (test mode) + SQLite ledger.

## Verify (smoke)

```bash
cd /workspace/research-mcp
npm install
npm run build
API_KEYS=dev-key-1 npm start
```

In another shell:

```bash
curl -s http://127.0.0.1:3000/health
# expect: {"status":"ok","version":"0.1.0"}
```

MCP endpoint: `http://127.0.0.1:3000/mcp`  
Auth: `Authorization: Bearer <key>` or `X-API-Key: <key>` (keys from `API_KEYS`).

```bash
docker run --rm -p 3000:3000 -e API_KEYS=dev-key-1 research-mcp:0.1.0
```

## Pricing (stub) + charge gate

Prepaid credit SKU (encoded in usage logger / docs):

| Depth | Price |
| --- | --- |
| quick (lite) | $0.25 |
| standard | $0.60 |
| deep | $1.50 |

**Charge gate:** charge only golden-matched or live-fetched + quality-bar-passing.  
Quality bar fail = no charge. Sample/demo path = no charge (`estimatedCostUsd: 0`, `charge_usd: 0`, `billable: false`).  
Snippet-only `LIVE_RESEARCH` leads = no charge.

Metering: stdout JSON + SQLite ledger debit for customer keys (path C prepaid packs).
